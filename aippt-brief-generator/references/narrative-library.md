# 叙事结构库

根据演示目标选择一个主结构。不要把多个结构机械拼接。

## 决策与提案

- **结论先行**：总判断 → 分论点 → 证据 → 行动建议。
- **问题—洞察—方案**：问题 → 根因 → 洞察 → 方案 → 证明 → 行动。
- **金字塔表达**：顶层结论 → 并列分论点 → 证据 → 综合建议。
- **战略地图**：愿景 → 战略目标 → 核心路径 → 能力 → 指标 → 里程碑。
- **提案说服结构**：机会 → 客户问题 → 独特方案 → 执行 → 回报 → 决策请求。
- **多方案比较**：评价标准 → 方案说明 → 横向比较 → 推荐 → 风险与取舍。
- **行动路线图**：目标状态 → 当前差距 → 阶段任务 → 资源 → 里程碑 → 指标。

## 汇报与复盘

- **数据证据链**：结论 → 指标现状 → 基准 → 原因 → 验证 → 决策建议。
- **前后对比**：现状 → 痛点 → 方法 → 结果 → 差异 → 下一步。
- **案例拆解**：背景 → 动作 → 过程 → 结果 → 原因 → 可复制方法。
- **时间线叙事**：按时间节点推进，每个节点保留事件、影响和下一阶段。
- **研究报告结构**：研究问题 → 方法 → 发现 → 解释 → 限制 → 建议。
- **实验过程**：假设 → 方法 → 变量 → 结果 → 分析 → 下一轮。
- **趋势演变**：过去 → 当前信号 → 驱动因素 → 情景 → 影响 → 应对。
- **成长复盘**：目标 → 行动 → 结果 → 偏差 → 经验 → 下周期计划。

## 产品与用户

- **用户旅程**：目标 → 触点 → 行为与情绪 → 阻碍 → 机会 → 优化。
- **场景化讲述**：真实场景 → 人物任务 → 阻碍 → 方案 → 结果。
- **产品发布节奏**：痛点 → 产品亮相 → 价值 → 功能演示 → 证据 → 行动号召。
- **品牌故事**：起点 → 信念 → 问题 → 行动 → 证明 → 邀请加入。
- **服务蓝图**：用户阶段 → 前台触点 → 后台支持 → 服务证据 → 断点 → 优化方案。

## 教学与解释

- **一页一观点**：每页一个完整判断，正文只支撑该判断。
- **问答推进**：连续关键问题作为章节，每个回答引出下一问题。
- **概念图解**：定义 → 组成 → 关系 → 示例 → 应用 → 总结。
- **课程式讲解**：学习目标 → 先验知识 → 概念 → 示例 → 练习 → 回顾。
- **清单式说明**：完整框架 → 逐项解释优先级、方法与检查标准。
- **空间导览**：总览 → 区域顺序 → 每区重点 → 路线体验 → 总结。

## 故事与编辑表达

- **故事递进**：背景 → 冲突 → 转折 → 洞察 → 方案 → 结局。
- **人物线索**：人物背景 → 目标 → 冲突 → 选择 → 变化 → 启示。
- **视觉散文**：少量文字与连续视觉意象推进，最后收束观点。
- **纪录片式**：事实现场 → 人物声音 → 数据背景 → 冲突 → 观察 → 结论。
- **杂志专题**：封面观点 → 导语 → 多角度章节 → 案例侧栏 → 编辑总结。
