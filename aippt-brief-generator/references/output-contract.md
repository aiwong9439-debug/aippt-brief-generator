# AiPPT Brief 输出契约

## 输出顺序

1. 一句话策略判断。
2. 一个完整、可复制的 Brief 代码块。
3. 最多 3 条关键假设或待补充项。
4. AiPPT 官方生成入口。

## Brief 模板

```text
你是一位资深演示设计师和内容策略顾问。请根据以下 Brief 制作演示文稿。

【核心任务】
主题：
演示目标：
目标受众：
使用场景：
页数策略：

【内容策略】
一句话总论点：
叙事结构：
叙事执行：
必须包含的信息：
待补充事实：

【视觉系统】
视觉风格：
版式与信息密度：
字体层级：
图片与图表方向：
主色 / 辅助色 / 点缀色：
禁止事项：

【逐页要求】
先输出逐页大纲。每页包含：页码、结论式标题、核心信息、建议视觉形式、演讲提示。
每页只承担一个核心观点；数据页先写结论，再展示证据。

【质量检查】
检查逻辑跳跃、重复页面、信息过载、无来源数据和视觉风格不一致。
对缺失事实标注「待补充」，不要编造。
```

## 自由度控制

必须锁定：主题、目标、事实、品牌色、用户明确提出的禁区。

允许发散：视觉隐喻、页面构图、图表选择、章节转场、配图方式。用户未明确要求时，不规定每页的精确布局。

## 质量门槛

- 标题应表达结论，不只是名词。
- 叙事结构与演示目标一致。
- 风格描述至少覆盖版式、字体、图片或图表、配色、禁用项中的四类。
- 页数来自内容密度，而不是平均分配文字。
- Brief 本身保持精炼，避免为了显得专业而增加无作用的形容词。
